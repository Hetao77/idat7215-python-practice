AI、ML、DL 与 agent 的层级

AI 是更广的领域；ML 通过数据学习模型；DL 是 ML 中使用多层神经网络的一类方法。视觉、语言、语音、机器人等方向可与这些方法交叉。AI agent 描述目标导向的系统和行动流程，并非某个固定网络结构。

AI ⊃ Machine learning ⊃ Deep learning

一个神经元究竟在做什么

z = ∑j wjxj + b； a = φ(z)
量作用易混处
输入 x特征或前层输出不是目标标签
权重 w控制特征对加权和的贡献训练更新的是参数
偏置 b平移加权和与激活位置不是随机误差；也不等于 loss
激活 φ把 z 变成神经元输出既不同于损失函数，也不同于优化器
损失 L量化预测与目标的差异反向传播求它对参数的梯度
学习率 η调节参数更新步幅一般不是对最终权重整体做比例缩放

令扩展输入 x̃ = [1, x₁, …, xd]ᵀ、扩展权重 w̃ = [b, w₁, …, wd]ᵀ，偏置就可以并入点积。这解释了练习 4/5 第一维恒为 1 的意义；计算时仍按给定四维规则，不能再增加一个偏置。

激活函数速查

函数形式与范围本次连接 / 求导提醒
Signumz>0 为 1；z=0 为 0；z<0 为 −1练习 4 按题给零点约定；不能用别的教材替换
Identityf(z)=z；实数练习 5；导数为 1，保留连续预测
Sigmoidσ(z)=1/(1+e−z)；(0,1)LSTM 门；σ′(z)=σ(z)[1−σ(z)]
Tanh(ez−e−z)/(ez+e−z)；(−1,1)练习 6 与 LSTM 候选；导数为 1−tanh²(z)
ReLUmax(0,z)；[0,∞)常见隐层激活；正半轴导数 1、负半轴 0，零点按约定处理

非线性激活使网络能够表达更复杂关系。若所有层只有仿射变换，(W₂(W₁x+b₁)+b₂) 仍可合成一个仿射变换。不能把“多堆几层线性层”当作获得非线性表达能力。

训练术语与数据准备

术语具体含义
Forward pass用当前参数依次得到中间激活、预测和损失。
Backward pass沿计算图用链式法则求各参数的梯度。
Iteration通常一次参数更新；练习 4/5 各有两次更新。
Mini-batch一次更新所用样本子集；本题每批两个样本。
Epoch完整经过训练集一次；两批合计覆盖四个样本一次。
Online / SGD逐样本更新；第 3 章线性回归例就是这种顺序。
Full-batch用整个训练集汇总后更新。
Feature scaling将量纲或数值尺度调整到可比范围，使优化和距离度量更合理；缩放参数应从训练集估计。
One-hot类别用一个 1 和其余 0 编码；输出位置的类别顺序必须固定。

同为“水果分类”，训练算法、输出激活与目标编码也可能不同。先读题给的网络、损失和更新规则，不能把一个例题的规则直接套给另一题。

选择题 2 BPE 每轮按什么准则合并

In the Byte Pair Encoding algorithm, what criterion determines which pair of adjacent tokens is merged in each iteration?

选项内容
A最低 cross-entropy loss（录屏答案页）
B最高 co occurrence frequency
C最大化 language model likelihood
D最小化 Unigram loss

Ans 为 B。统计语料中所有相邻符号对，合并当前出现最多的一对；在更新后的符号序列上重复，直到达到所需词表大小。

  1. 从字符等基础单元开始 统计相邻对的出现次数。
  2. 选择当前频率最高的一对 建立一个新的合并单元。
  3. 更新语料分割与词表 再重新统计合并 逐步形成子词。

Unigram 的定义和词频例子

Unigram 是独立看待的一个 token，可以是词、字符或子词，不考虑周围上下文。课件句子 AI improves manufacturing efficiency 包含 AI、improves、manufacturing、efficiency 四个 unigram。

P(w) = Count(w)Total tokens

例题语料为 robot AI robot factory robot AI，共 6 个 token。

Token次数Unigram probability
robot33/6 = 0.5
AI22/6 ≈ 0.333
factory11/6 ≈ 0.167

因此，从这段语料随机抽取一个 token，有一半概率是 robot。这里统计的是单个 token 的边际出现概率，没有使用前后词顺序。

Unigram 词表构建的自顶向下流程

与 BPE 相反，课件流程图从较大的候选词表出发。先产生候选字符和子词，估计 token 概率并寻找语料分割；然后评估删除 token 对语料 likelihood 的影响，剪去贡献较小的 token，更新词表并重复，直到达到目标大小。图中还标出 EM 估计、Viterbi 分割以及保留单字符等步骤。

需要抓住的答案是“BPE merges，Unigram prunes”。不必把词元剪枝理解为固定地把完整单词拆碎；算法是在候选词表中删除不够有用的单元，并重新评估语料的分割。

Unigram loss 及其作用

课件另用 Unigram loss 描述一种让模型预测分布接近预先给定 unigram 分布的辅助损失或正则项。设目标分布为 pᵢ，模型预测为 qᵢ，词表大小为 V，其形式是交叉熵。

Lunigram = − Σi=1V pᵢ log(qᵢ)

课件给出三项用途：减少预测过度集中、帮助照顾低频词、作为语音识别或语言模型主损失之外的辅助目标。这与上面的 tokenizer 词表剪枝是两个讲解层面，不能把该辅助损失直接写成 BPE 的合并标准。

补齐：标准公式、门值和手绘顺序

以下用 c̃ₜ 表示候选记忆，与原记录的 gₜ 同义。令 uₜ=[hₜ₋₁,xₜ]，标准无 peephole 的 LSTM 可写为：

ft=σ(Wfut+bf)；it=σ(Wiut+bi)
c̃t=tanh(Wcut+bc)；ot=σ(Wout+bo)
ct=ft⊙ct−1+it⊙c̃t；ht=ot⊙tanh(ct)

⊙ 表示逐元素乘；c 是 cell state，h 是 hidden state。公式与原课件第 70、74、76、79 页相合，也可核对 PyTorch LSTM 文档。

  1. 先画 cₜ₋₁ → 乘 fₜ → 加法 → cₜ。
  2. 加一支候选 c̃ₜ，与输入门 iₜ 相乘，接入加法节点。
  3. 由新 cₜ 分支，经 tanh 后乘 oₜ，得到 hₜ。
  4. 标出 xₜ、hₜ₋₁ 共同生成门和候选内容，标明状态传到下一步。
条件含义不能推出
fₜ≈0抑制旧状态的保留项不代表新 cₜ 必为 0，新内容仍可写入
iₜ≈0抑制候选内容写入不代表旧状态必被删除
oₜ≈0抑制当前 hₜ 输出不代表 cell state 必清零

普通 RNN 可写 hₜ=tanh(Wₓxₜ+Wₕhₜ₋₁+b)，由一个隐状态反复传递。LSTM 的可控加法记忆通路有助于缓解长期依赖学习困难，但不是绝不遗忘或永不梯度消失的保证。“memory efficiency”比较资源占用，和“能保留多远信息”是不同问题。

GRU 的最小复习要求

Update gate 调节旧状态与候选状态的混合；reset gate 调节生成候选时使用多少旧信息。它没有独立的 LSTM cell state，也没有独立 output gate。不同资料可能把 z 或 1−z 分配给相反项；考试应按题给定义解释“保留多少/更新多少”，不脱离公式硬背。

Attention：Q、K、V 分别干什么

符号含义理解
Query Q当前 token 要寻找的信息我需要什么？
Key K用于匹配的信息表示我能被怎样检索或匹配？
Value V按注意力权重汇总的内容匹配后取用什么内容？

点积 QKᵀ 得到匹配分数，按 √dₖ 缩放并施加必要 mask 后，softmax 得到权重，再对 V 加权求和。

Attention(Q,K,V) = softmax(QKᵀ / √dk) V

Token 可以直接联系较远位置的信息，不必仅靠多次隐状态传递。位置编码/位置表示补充序列顺序；self-attention 本身不能单靠排列无关的集合运算得知先后。因果语言模型还需遮住未来位置。

训练时，适当的并行计算能提高效率；自回归生成仍需逐步产生后续 token。“Transformer 完全没有顺序”“永远不需要 mask”“attention 保证理解指代”都过度概括。标准稠密注意力的 n×n 权重矩阵也解释了练习 7 的二次方复杂度干扰项。

先写下自己的解答，再展开参考。以下全是整理补充或变式，原练习仍以练习 1–8 为准。

1. 数字识别输出也是数字，为什么不是回归？

数字是类别名称；目标是选择 0–9 中哪一类。回归的目标量有连续数值意义，例如温度。

2. 无标签数据一定属于无监督学习吗？

不一定。机器人用动作及奖励学习策略时，也未必有每步正确标签，但属于强化学习。必须检查学习信号和任务目标。

3. 只写“AI 没感情所以无法替代人类”能充分回答评论题吗？

通常不充分。应先界定任务与替代范围，再按机制、例子、限制和条件性结论论证。某任务是否需要情感能力也应由题目场景决定。

4. x=[1,3]ᵀ、w=[0.2,−0.1]ᵀ、y=1、η=0.05，按残差规则分别用 sign 与 identity 更新一次。

共同 z=−0.1。Sign：ŷ=−1，e=2，Δw=[0.1,0.3]，新 w=[0.3,0.2]。Identity：ŷ=−0.1，e=1.1，Δw=[0.055,0.165]，新 w=[0.255,0.065]。

5. mini-batch 内先算样本 1，立即改权重，再算样本 4，有什么问题？

改变了题给的批次更新语义，变成逐样本更新。批内所有预测应使用同一旧权重，贡献合并后才更新。

6. 沿用练习 6，只把 y_true 从 0 改为 1，四个梯度怎样变化？

前向值不变，误差改为 0.5231883119。两个 v 梯度各约 0.3984571608，两个 w 梯度各约 0.2197256668。原答案不能直接照抄。

7. 练习 6 改成 x=2、真值 0、四个权重仍为 1。只把原 w 梯度乘 2 可以吗？

不可以。tanh(wⱼx)、网络输出、误差和局部导数都改变。此时 ŷ=2tanh(2)≈1.92805516；两个 v 梯度各约 1.85869835，两个 w 梯度各约 0.27243737。

8. BPE 可以把一段文字里最常出现、但并不相邻的两个词合并吗？

不能。此题统计当前切分中的相邻 token 对，并按出现频数合并；频率高不够，还必须相邻。

9. p=q=[0.5,0.5] 时，自然对数交叉熵是多少？
−0.5ln0.5−0.5ln0.5=ln2≈0.69314718

不是 0；这里 KL(p∥q)=0，而交叉熵=H(p)。

10. Unigram 是概率模型，为什么仍可每次输出同一种切分？

固定词表、概率、最优路径算法与平局规则时，最大概率切分可以是确定的。随机采样是另一种可选策略。

11. LSTM 的 fₜ=0 与 oₜ=0 分别影响哪里？

前者消除该位置旧 cell state 的保留项，但输入分支可写入新内容；后者抑制当前 hₜ 输出，并不自动清除 cₜ。

12. 同一个 RBF 中心，d=0.5、σ=0.5，响应是多少？σ 变成 1 呢？

先算 φ=exp[−0.25/(2×0.25)]=exp(−0.5)≈0.60653066。σ=1 时 φ=exp(−0.125)≈0.88249690；宽度变大，同距离处响应更高。

13. 单神经元 ŷ=wx+b，L=(ŷ−y)² 与 L=½(ŷ−y)² 的梯度相同吗？

不同。前者 ∂L/∂w=2(ŷ−y)x；后者为 (ŷ−y)x；偏置梯度同样相差系数 2。给定学习率下更新幅度也会不同。

14. RNN 与 Transformer 的长距离信息通路如何比较？

普通 RNN 依靠连续时间步隐状态传递；self-attention 允许相关 token 直接建立联系。Transformer 仍须表示位置，并考虑 mask、计算资源与任务条件；直接联系不保证每次推断正确。
